# Phase 8 report — reliability and quality test checkpoint

This is a marked development test build, not full Windows/client certification. The explicit manual matrix in WINDOWS-VALIDATION.md remains open; Flutter is not being replaced.

Implemented: latest-open generation/cancellation protection; recoverable failed-open library view; crash-safe controller teardown, script/filter/event cleanup and generation-bound messages/failures; bounded off-thread bridge parsing; approved resource-tree validation that rejects filesystem links before virtual-host mapping; nonmapped request filtering and offline lab policy; selected-origin browser-data reset with confirmation; serialized save/load UI actions and shutdown message suppression; background bounded/rotated local logging; off-thread image/SVG validation and save payload checks; stricter SVG external/style-reference rejection and linked-save-directory rejection. Initial window size now scales from DIPs; stored physical placement is retained, and zoom reapplies when XamlRoot/DPI changes. Library/console/image action rows scroll instead of clipping; dialog widths adapt to the window.

Changed files: App runtime/window/dialog/layout services and native quality/benchmark runners; Core resource policy; Player save validation/input script cleanup; focused tests; authored offline workload/video and benchmark tooling; quality matrix/docs. No package dependency added. Channel-based logging uses the existing .NET runtime. Virtual-host files bypass WebResourceRequested, so the resource-tree check is separate; no claim is made that a request callback mediates mapped files.

Required checks: restore and Release build passed without warnings/errors; 36 Core/persistence and 16 Player tests passed (52 total). Final native suite `artifacts/native-smoke-c00624b220d8453bb11bc90dc43dcc6b/report.json` passed six actual stories including Accidental Mind 3.4, presentation/input/library/fullscreen/console checks, ten reopens, overlapping opens, junction rejection, scoped data reset, denied external navigation/geolocation, malformed message rejection, native UIA names/roles, scoped directional dialog focus and isolated browser crash/recovery with retained data. Save compatibility passed all four stages for Accidental Mind in `native-save-smoke-0ddc64cf1b7941a290cb62d70b39291c` and genuine SugarCube 1.0.35 in `native-save-smoke-2a7b6c8c16994c36ac26c13a34aa53f0`. Tests write disposable copies only. DOM/package results follow in EXECUTION.md.

One benchmark instrumentation trial had a browser exit/CDP timeout; completed Flutter rows were retained, its failed WinUI case was excluded, and a settled-initialization retry without WinUI's unnecessary Page.bringToFront passed all four native cases. That failure's exact cause is unproven; it is not presented as a fixed product regression or a successful test.

Performance observations: eight completed cases compare the same authored idle/CSS/canvas/local-video/scroll workload and Accidental Mind on this host with fresh/reused browser profiles. See BENCHMARKS.md for numbers and limitations. Outer host windows, entry-point initialization and OS cache conditions differ; startup is a rendered-document proxy and frame intervals are not input latency. No overall performance superiority is claimed. The standalone benchmark Flutter wrapper is archived separately and normal main.dart output was rebuilt successfully; Flutter source remains unchanged.

Physical keyboard/Tab/Escape, screen-reader narration, high contrast, reduced motion, text scaling, touch usability, mixed DPI/refresh, display disconnection, extended sessions, media/audio, close during capture/load and VoidLink/Quest clients remain unverified.
