# Phase 7 report — adaptive input, command bar and offline lab

Implemented Auto/Compact/Comfortable interaction profiles. Auto consumes activation events, ignores hover/synthetic DOM events and uses the reference 350 ms change guard. Native chrome uses routed pointer metadata; browser input uses trusted passive DOM listeners with validated origin/type/shape. User profile selection takes precedence. No edge gestures or raw keyboard hooks are installed.

The Comfortable bottom bar supports collapse/expand at a fixed leading position, start/center/end alignment, left/balanced/right reach, 44/48/56 DIP targets, command reordering, optional Page Up/Down and pinned Console immediately before rightmost More. Narrow middle commands scroll horizontally while pins remain available. More exposes fullscreen, zoom, assistance, reload, settings, diagnostics, lab and Open. Preferences persist in SQLite, read retained Flutter command-bar settings, and reset explicitly. Page buttons call the canonical Flutter page-scroll helper.

Diagnostics are disabled by default, session-only and bounded to 200 entries with the latest 40 in exported reports. Metadata contains allowed categories/device kinds, button/contact counts, origin and validated bounded build identity. Reports omit automatic story text, paths, filenames, key values, coordinates and timestamps. Session labels are sanitized/bounded user input. Clear/copy and explicit enable/disable controls are available. Native browser instrumentation counts active contacts through cancellation without storing pointer IDs in reports; canonical reference diagnostics remain off to avoid duplicate events.

Input Lab packages the original Flutter offline fixture without changing it. Launch requires confirmation; diagnostic consent resets off, and it creates no Games/history entry. Reload retains transient lab mode. All form/image/dynamic-choice/canvas/SVG/scroll scenarios remain in the bundled HTML. The lab has no network resources. Ordinary game source/save folders are unchanged.
